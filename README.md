# Prashant Singh — Portfolio

Personal portfolio built with **Next.js (JavaScript)** and **Tailwind CSS**.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

Static files are generated in the `out` folder (ready for Netlify).
